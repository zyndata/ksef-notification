## Config flow wizard

| # | What it asks |
|---|---|
| 1 | **KSeF access** — environment, the company's NIP, the KSeF token. Verified against KSeF before it is accepted. |
| 2 | **Notification** — the phone to notify, and which invoice fields the message carries. |
| 3 | **Behaviour** — how often to check. |

Everything except the company's identity is editable later through the options flow.

## Selectable invoice fields

The user picks any subset. The candidate list below is the starting point; phase 0 assigns each
field to its source, phase 1 finalizes the list, the labels and the formatting.

"Source" matters: fields from the **metadata** cost nothing extra, while a field from the
**XML** means one more request per new invoice. The XML is fetched only when at least one
selected field needs it.

| Field | Expected source | Notes |
|---|---|---|
| Seller name | metadata | |
| Seller NIP | metadata | |
| Invoice number | metadata | |
| Gross amount | metadata | with currency |
| Net amount | metadata | with currency |
| VAT amount | metadata | with currency |
| Issue date | metadata | |
| Invoice type | metadata | e.g. VAT, correction |
| KSeF number | metadata | the invoice's identifier in KSeF |
| Payment due date | XML | |
| Payment form | XML | transfer, card, cash… |
| Bank account | XML | |
| Line items | XML | TODO (phase 1): count, first few descriptions, or both |

"Expected source" is unverified until phase 0.
